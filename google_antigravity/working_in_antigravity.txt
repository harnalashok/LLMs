App vs IDE
---------
The main difference is that the Antigravity App (Antigravity 2.0) 
is a standalone desktop command center for managing and orchestrating
autonomous AI agents across projects, while the Antigravity IDE is a 
full code editor (forked from VS Code) built for direct, line-by-line
software development and debugging.

 What is Slash command: /plan
	Typing /plan inside the chat box in the 'Google Antigravity App' 
	triggers a multi-phase analysis and planning workflow instead of
	executing code right away.

	What Happens Step-by-Step

	 Analysis and Discovery: The agent inspects your prompt, scans
				  your workspace configuration, and 
				  examines the affected files.	
				  
	 Clarification and Interviewing: If your request is ambiguous or has 
	 				 multiple technical paths, the agent asks 
	 				 targeted questions or runs a structured 
	 				 interview to narrow down the scope.
	 				 
	 Implementation Plan Artifact Creation: Once requirements are clear, the
					 agent generates a structured technical 
					 document (an implementation_plan.md style 
					 artifact) detailing the exact codebase changes 
					 needed. 
					 
	 User Review and Approval: The plan pops up in the review pane. You can inspect
	 			  the steps, leave inline comments or feedback, and click
	 			  Proceed to start implementation or request
	 			  changes				 				 			     

	 When to write /plan: You should write /plan and your prompt together in
	 		      the same message, then press send. 
	 		      For example, you would type this all at once into the 
	 		      chat box and hit enter:
	 		      
	 		      /plan refactor the authentication middleware to use JWT tokens
	 		      
	How the Interface Processes It

		• The slash command /plan acts as a modifier: It tells the app's AI agent 
		  how to process the text that follows it.
		• If you just type /plan and hit enter: The app will likely ask you what 
		  you want to plan, requiring an extra step.
