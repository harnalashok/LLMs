Using PGAdmin4
==============
Tasks:

	a. Create adminServer: user postgres
	b. Create goatServer : user goat
	c. Transform database to vector database: user postgres

### Task a. For superuser ############33

#1. Set password for postgres user:

sudo -u postgres psql -c "ALTER USER postgres PASSWORD 'postgres';"

#2.
Start PGAdmin4. It has its own browser like Window.

# 3. 
Right click on Servers in the right-panel and click 
	Register-->Server

# 4.
Now fill up as follows:

Tab: General	
	Name: adminServer
Tab: Connection
	Host Name/Address: localhost
	Port: 5432
	Mainetenace Database: postgres
	Username: postgres
	password: postgres
	
Click Save

# 5.
Right-click on Login/Group Roles.
Click Create Login/Group Roles:
Tab: General
	Name: Your username (goat)
Tab: Definition
	Password: Give password (goat)
Tab: Privileges:
	Select Privileges
	At the leats: Can Login
		      Create Databases
		      

# 6. 
Right-click on Create Databases 
Click Create Database:
Tab: General
	Give database name, (goat) 
	Owner: Write user name created above (goat)

# 7.
Right-click on adminServer
And click Disconnect from Server.

### Task c. For normal user ############33

# 8. 
Right click on Servers in the right-panel and click 
	Register-->Server


# 9.
Now fill up as follows:

Tab: General	
	Name: Say goatServer
Tab: Connection
	Host Name/Address: localhost
	Port: 5432
	Mainetenace Database: goat
	Username: goat
	password: goat
	
Click Save

# 10.
	NOW YOU SHOULD BE ABLE TO CREATE A DATABASE AND TABLE
	ALWAYS HAVE A PRIMARY KEY IN THE TABLE.
	Data types for table:
		i)   integer
		ii)  character
		iii) character varying 
	 	     (Not character varying[])

#### Task c. Vector Database ##########

# 11
# Transform 'goat' to vector database

# 12.
Disconnect connection as 'goatServer'
AND Connect as adminServer

# 13.
Look for Database: 'goat'

# 14.
Right click on it and click 'Query Tool'

# 15. Execute:
CREATE EXTENSION IF NOT EXISTS vector;

# DONE. The database is transformed to vector database
