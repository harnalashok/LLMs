# 3.0.4

	Context Required?:
	-----------------
	    Do I need to specify 'context' for the second task.
	    When is a context needed to be specified for a task? 
	    For example, there are two tasks, task1 and task2, 
	    each with the respective agents: 'Financial Analyst' and 'Market Analyst'.
	    Market Analyst' is to write the analysis after financial researcher
	    has done his work. We create two agents, attach tasks to each 
	    but no context is specified to 'task2' task. The 'Market Analyst' 
	    does work and gives output.

	Answer:
	------
	    In sequential execution, if you don't specify context on task2,
	    CrewAI defaults to giving it the output of all previously 
	    executed tasks anyway.
	    So task2 (Market Analyst') still receives
	    task1's (researcher's) output automatically, since sequential
	    tasks by default use prior tasks' outputs as context. That's 
	    why it worked without explicit context.
	    Explicit context is needed when you want to:
		a.    Control which specific prior task(s) output are passed (not all previous ones)
		b.    Use a non-sequential/parallel or hierarchical setup where default ordering context isn't guaranteed
		c.    Explicitly exclude a task's output from context (using context=[])

from crewai.tools import BaseTool
from pydantic import Field
from langchain_community.tools.polygon.financials import PolygonFinancials
from langchain_community.utilities.polygon import PolygonAPIWrapper


# 3. Initialize the wrapper and the specific tool

class PolygonFinancialsTool(BaseTool):
    name: str = "Polygon Financials"
    description: str = "Fetch financial data from Polygon."
    polygon: PolygonFinancials = Field(default_factory=lambda: PolygonFinancials(api_wrapper=PolygonAPIWrapper()))
            
    def _run(self, query: str) -> str:
        return self.polygon.run(query)
